# Piloto comercial en Valladolid (5 talleres)

Material para preparar el piloto. **Nada de esto se envía ni se publica sin autorización de la usuaria.**

| Documento | Para qué |
| --- | --- |
| `propuesta-piloto.md` | Propuesta de 14 días gratis, condicionada a estar listos para datos reales |
| `mensajes-contacto.md` | Llamada o visita, correo y WhatsApp (estos dos solo con consentimiento), seguimiento |
| `guion-demo-10-min.md` | Demostración de 10 minutos con la demo pública |
| `preguntas-validacion.md` | Preguntas para validar el problema y los 29 €/mes |
| `requisitos-piloto.md` | Requisitos técnicos y legales pendientes, con lo que bloquea el inicio |
| `privado/` | **No se sube a GitHub.** `candidatos.md` (los 5 talleres con sus fuentes) y `seguimiento.csv` (registro de contactos) |

## Cómo usar el seguimiento (`privado/seguimiento.csv`)

Se abre con Excel o LibreOffice (separador `;`). Una fila por taller. Estados, en este orden:

`pendiente de contactar` → `contactado` → `demo agendada` → `demo hecha` → `piloto acordado` (con fecha) → `piloto en curso` → `continúa` / `no continúa`; o `descartado` (con el motivo en «notas»).

Columnas clave:

- **consentimiento_correo_whatsapp:** `sí (fecha, canal)` antes de escribir por esos canales.
- **pagaria_29**, **condicion_exito_14_dias**, **precio_caro** y **precio_barato:** respuestas literales a `preguntas-validacion.md`.
- **proximo_paso** y **fecha_proximo_paso:** nunca dejar un taller sin siguiente paso.

Objetivo: al menos 3 de 5 talleres con interés fuerte y 2 que acepten 29 €/mes si se cumple su condición de éxito.
